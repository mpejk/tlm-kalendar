# DECISIONS

- **Node.js install (16 Nov 2026).** The machine had no Node and no package manager (no Homebrew). Node 24.22.3 and npm 12.2.2 were unpacked from the npm registry tarballs (`node-bin-darwin-arm64`, `npm`) into `tools.nosync/` inside this folder — nothing installed outside the project. Use `export PATH="$PWD/tools.nosync/bin:$PATH"`.
- **`.nosync` folders.** The project sits in iCloud Drive. `tools.nosync/` and `node_modules.nosync/` (symlinked as `node_modules`) carry the `.nosync` suffix so iCloud does not try to sync tens of thousands of dependency files.
- **Git identity.** No global git identity was configured; commits use the GitHub no-reply address of the signed-in `gh` account so no private e-mail is published.
- **TLS for Node.** Node rejected the certificate chains of the npm registry and the old site (`UNABLE_TO_GET_ISSUER_CERT_LOCALLY`); certificate checking stays on and Node is pointed at the macOS trust store with `NODE_OPTIONS=--use-system-ca`. Page downloads go through the system `curl`.
- **Build tool.** esbuild (bundling TypeScript into classic IIFE scripts) instead of Vite/Astro: the site must run from `file://` with script-tag data and no ES modules, which is esbuild's plain output; Vitest and Playwright as suggested.
- **Divinum Officium data.** Sparse shallow clone of `web/www/missa/Latin`, `web/www/Tabulae` at commit d6c8066 (15 Nov 2026) into `data/raw/do/repo` (`git clone --depth 1 --filter=blob:none --sparse https://github.com/DivinumOfficium/divinum-officium repo && git sparse-checkout set web/www/missa/Latin web/www/Tabulae`). Data files only are read; no DO code is run. The clone is git-ignored; the imported corpus is committed.
- **DO Commons.** The Mass Commons (`C1`…`C12`) now live in `web/www/horas/Latin/Commune` in the DO repository (shared with the Office), so that folder is checked out too (`git sparse-checkout add web/www/horas/Latin/Commune`).
- **2019 Mass pages.** The 2017/2018 URL pattern was probed under `/kalendar/2019/` for the first 15 dates; all returned 404, so 2019 is a calendar oracle only (`data/raw/site/missing.txt`).
- **Harvest result.** 3 year pages, 823 Mass pages and 4 rite pages (827 of 827 links on the 2017 and 2018 year pages). The 59 overlapping calendar days (Dec 2017, Dec 2018) agree exactly between year pages.
- **OCR.** tesseract is not installed and there is no package manager; the rubrics PDF was OCR'd with the macOS Vision framework (`scripts/ocr/ocr-pdf.swift`) into `data/rubrics/1962rubrics.txt`. Paragraph numbers cited in code and tests were read from that text.
- **Sanctoral table.** `data/calendar/sanctoral.yaml` (329 entries) was built by layering the DO kalendar tables up to 1960 (which Mass file belongs to which date) and joining them by date with the Croatian titles of the old site's year pages; classes were checked against the old site rows. Three saints the old site never showed in 2017–2019 (Sts Soter and Caius, St Margaret of Scotland, St Maurice) have titles worded in the same style (`own: true`).
- **Engine results.** 1130 of 1130 old-site days reproduced (DIFFS.md). Against Missale Meum 2026–2036 the celebration of the day agrees everywhere except the vigil of St Lawrence on Saturdays and the 2035 transfers; all differences are categorised with rubric citations in MM-DIFFS.md.
- **Pope oration.** Kept on the anniversary date whatever the class of the day (the old site printed it on a I class Sunday of Lent and on St Joseph), except in the Sacred Triduum.
- **St Joseph / Annunciation 2035.** Annunciation on Monday 2 April (n. 96a, its proper place), St Joseph on Tuesday 3 April (n. 96); Divinum Officium's transfer table agrees, Missale Meum has the reverse.
- **Independent derivation of the edge dates** (fresh subagent, rubrics text only; kept as EDGE-DERIVATION.md). It agreed with the engine everywhere except: (1) the vigil of St John on 23 June 2033 — it is omitted because the feast is transferred (n. 33); the engine was corrected; (2) the commemoration of St Sixtus / St Theodore when the Transfiguration / Lateran Dedication replaces a Sunday — the subagent would keep it under n. 111c; the engine omits it as the old site does (6 Aug 2017), reading n. 16a ("with all rights and privileges") as importing the Sunday limit of n. 111b. It also noted that n. 98 could be read to put St Joseph before the Annunciation in 2035; n. 96a and Divinum Officium decide for the Annunciation on the Monday.
- **Divinum Officium snapshot (supersedes the entry above).** The current DO master has merged the Mass Commons into the Office files and several Mass files now point to the wrong Common (e.g. the Gospel of the Conversion of St Paul, the postcommunion of St Anastasia). The import therefore reads the last self-consistent state, commit 326bc4afd27afb9e9275d2eeef9558d3907738d3 of 27 Feb 2025 (`git fetch --depth 1 origin 326bc4a…`, `git sparse-checkout set web/www/Tabulae web/www/missa/Latin web/www/horas/Latin/Commune`, `git checkout --detach 326bc4a…`). Evaluated for "Rubrics 1960".
- **Latin overrides.** Where the old site prints the 1962 text and the DO file differs or lacks the section (Chrism Mass psalter, Seven Sorrows, third Mass of All Souls, a few saints), the old site's Latin is used: `data/corpus/overrides.yaml`, logged in `data/corpus/la/OVERRIDES.md`. Where the old site is the one in error, DO is kept and the case is listed in `data/verify/text-exceptions.yaml`.
- **Preface of holy popes.** The common (or seasonal) preface, as on the old site, not the preface of the Apostles that DO's rule files name for the Common of Supreme Pontiffs.
- **Creed on 26 December.** Said (n. 475d), although the old site says it is not.
- **Rogation Mass.** Offered as a second Mass on the Greater Litanies and the three Rogation days, with a commemoration of the office of the day when that is not a IV class feria, as on the old site.
- **Zagreb layer (16 Nov 2026).** HBK page re-read: same celebrations as in the brief. No pre-conciliar Zagreb proper (Proprium, Directorium 1961–64, local section of Kniewald) was found online in two searches, so rules 2–5 of the brief apply. Ranks by the Code of Rubrics n. 43 where it fixes them: **St Ladislaus (27 June), principal patron, I class; dedication of the cathedral (25 August), I class in the whole archdiocese, treated as a feast of the Lord; St Florian (4 May), secondary patron, II class.** Otherwise blagdan → II class (Sts Cyril and Methodius kept on 7 July, Our Lady of Bistrica 13 July), spomendan → III class (Bl. Alojzije Stepinac, St Leopold Mandić, St Quirinus, St Marko Križevčanin, St Demetrius, Holy Relics, St Nikola Tavelić); the five neobvezatni spomendani are notes only. Masses are the Commons of the 1962 Missal (printed with "N." — no name is inserted into a prayer), except St Florian, whose three prayers come from the proper of the Polish dioceses in the Divinum Officium data. Everything is in `data/local/zagreb.yaml`; change a `class` or `mass` there and run `npm run build`.
- **Rites.** Blessing of palms, Good Friday and the washing of the feet are shown exactly as the old site printed them (both languages). Candlemas (blessing of candles), Ash Wednesday (ashes) and the Easter Vigil are taken from Divinum Officium in Latin; the engine lists them as an extra tab before the Mass.
- **Fonts.** EB Garamond (SIL OFL), self-hosted from the `@fontsource/eb-garamond` npm package (Latin and Latin Extended subsets) plus the full font file from the Google Fonts repository on raw.githubusercontent.com, used only for ℟ and ℣; ✠ is drawn as an inline shape because the font has no such glyph. The font's Latin-language feature that turns u into v is switched off.
- **Playwright browser** is installed inside the project (`tools.nosync/pw`, `PLAYWRIGHT_BROWSERS_PATH`) so that nothing is written outside this folder.
- **Pope.** Leo XIV; Mass for the inauguration of the Petrine ministry on 18 May 2025 (confirmed online 16 Nov 2026). One configuration value: `POPE` in `scripts/build/data.ts`. The added oration is shown on 18 May, as the old site showed it on 19 March for Pope Francis.
- **Croatian matching.** A block's Croatian is the old site's cell whose Latin has the same proper words; typos and small Vulgate variants are tolerated, a different saint's name never is (`scripts/croatian/resolve.ts`). Where the old site prints the same Mass section with Latin that differs more, its Croatian is still used (`data/tm/manual.json`, built by `scripts/croatian/build-manual.ts`). `data/site-config.json` holds `croatianPrimary` (`site` or `kniewald`).
- **St Demetrius and companions (8 October, Zagreb).** Mass *Salus autem* (Common of several martyrs who were not bishops, `Commune/C3b`) instead of *Intret*, whose collect in the Missal speaks of martyr bishops. Change `mass` in `data/local/zagreb.yaml` to choose another Common.
- **Kniewald as the local source (run 4).** Kniewald's *Rimski misal* of 1942 carries the Croatian feasts inside its sanctoral: St Florian (4 May), St Quirinus (4 June), St Ladislaus (27 June), Bl. Augustin Kažotić (3 Aug), Bl. Marko Križevčanin (7 Sept), St Demetrius (8 Oct), the feast of the Holy Relics (5 Nov), Bl. Gracija (9 Nov), Bl. Nikola Tavelić (14 Nov), Bl. Ozana (27 Apr). He gives no ranks, and his dates agree with the HBK table (Bl. Gracija 9 Nov against HBK's 8 Nov; a note only), so rules 2 and 3 stand. His choice of Common is followed: St Florian *Protexisti* with the Epistle 1 Pet 1, 3-7 (replacing the prayers of the Polish proper used before); St Quirinus *Protexisti* with the Epistle of *Statuit* in Paschaltide and *Statuit* after it; Bl. Marko and Bl. Nikola *Laetabitur*; St Ladislaus *Os justi* (unchanged). Kniewald also prints proper prayers in Croatian for St Ladislaus, St Demetrius (whom he has as a single martyr, Mass *In virtute*), Bl. Marko, Bl. Nikola, Bl. Augustin, and a whole proper Mass of the Holy Relics; their Latin was not found in the Divinum Officium data nor by a search of archive.org, so the Common's prayers are shown (see BLOCKED.md). Compositions are in `data/local/formularies.yaml`.

## Review of November 2026 (revision 25a6b7a checked against the Missal of 1962 and the Code of Rubrics)

The findings, verdicts and counts are in `ODGOVOR-NA-PROVJERU.md`. Decisions taken while correcting, including those that reverse an entry above:

- **Authority for texts.** Missale Romanum, editio typica 1962, in the scan of the Church Music Association of America (`https://media.musicasacra.com/pdf/missale62.pdf`, 1088 PDF pages; downloaded to `data/raw/missale62/`, git-ignored; page images and OCR with `scripts/missal/page.swift` on a Mac). Every correction cites the printed page and the PDF page. The pages were read as images; an OCR of the whole book (macOS Vision, `scripts/missal/page.swift`) serves only to find the page.
- **Prayer for the Pope (reverses "Pope oration" above).** Code of Rubrics n. 449: added on the anniversary unless a day of nn. 1, 2, 3 or 8 of the table of precedence occurs; n. 450 with nn. 364 and 363b: then transferred, like the votive Mass, to the first day that is not of I class. In 2026–2036 only 2034 is affected (Ascension on 18 May, prayer on 19 May); on Whit Tuesday 2027 and 2032 and Ember Friday 2035 (I class, n. 10) it stays. The old site's 19 March cases (a Sunday of Lent, St Joseph) agree with this rule.
- **Rogation Mass.** With the Creed when it falls on a Sunday (nn. 343a, 475a). Not offered on days of I class (n. 341: a votive Mass of II class is allowed on days of II–IV class): 25 April 2030 (Easter Thursday) and 1 May 2035; the day carries a note (n. 343c). This departs from the old site on 25 April 2019, listed in `DIFFS.md`.
- **Feasts of Our Lady are marked** (`bvm: true` in `data/calendar/sanctoral.yaml`, 17 entries); a second commemoration or prayer of Our Lady is omitted (n. 112d), likewise a second of the Lord among the commemorations (n. 112a).
- **Corrections are data.** Latin: `data/corpus/patches.yaml`, applied whenever the corpus is loaded (no import run, no copy of Divinum Officium needed). Croatian: `data/tm/corrections.yaml`. Rites: `data/tm/rites-hr.yaml`. An entry that matches nothing stops the build. The build regenerates `data/tm/manual.json` first, and Croatian stored under an uncorrected Latin wording is still found after a correction (`nearKey` in `scripts/croatian/resolve.ts`).
- **Typos (reverses "nothing was corrected").** Obvious typos of the old site's Croatian, wrong Scripture references and misprints of the Latin data are corrected; `TYPOS.md` lists each with the original reading. Wording is not changed.
- **Alleluia.** Introit, offertory and communion follow nn. 429, 478 and 504 in the assembler (added in Paschaltide, dropped from Septuagesima to Easter); the Paschal Alleluia has an Alleluia after each verse (Missal, e.g. p. [22]). The Croatian is made to agree mechanically (`scripts/croatian/alleluia.ts`): only the word Aleluja is added, removed or moved to its own line.
- **Unicode.** The corpus is normalised to composed characters when loaded and the line-joining mark "~" of the source files is removed; 13 texts had decomposed accents, which hid Alleluias from the assembler's patterns.
- **Names (reverses "Prayers of a Common keep N.").** `data/calendar/names.yaml` gives the Latin forms by case and the Croatian forms; the assembler puts the Latin name in place of "N." by the case of the word before it, the build puts the Croatian name in place of "I." after *blaženoga / svetoga / blažene* (genitive) and in the prayers for the Pope. Where a form is not on record, or two or more unnamed saints are meant (St Demetrius and companions, Holy Relics), the placeholder stays. The bishop's name in the Exsultet stays "N.". All insertions are listed in `data/verify/name-insertions.json` and in the answer to the reviewer.
- **St Florian (4 May).** Not a bishop: the prayers "Pro Martyre tantum" of the Mass *Protexisti* (Missal pp. [10]–[11]), not those of a martyr bishop (`data/local/formularies.yaml`).
- **Easter Vigil.** The Mass after the Kyrie is taken from the same Divinum Officium file (`scripts/import/vigil-mass.ts` → `data/corpus/la/vigil-mass.json`), checked against the Missal p. 212. Croatian from Kniewald 1942, pp. 297–298 and 30, read on the page scans. The preface is the old site's Easter preface with Kniewald's variable words "osobito ove noći"; the antiphon at the Benedictus is the old site's sentence Mk 16, 2 from the Easter Gospel with Aleluja added. Psalm 150 and the Benedictus have no Croatian source and are listed in `ZA-PRIJEVOD.md`. Proper parts of the Canon are not shown (the reviewer did not ask for them).
- **Exsultet.** Its last paragraph (1955) is shown as a row of its own without Croatian; the rest keeps Kniewald's text.
- **Good Friday, prayer for the pagans.** Kniewald's sentence (1942, p. 263) replaces the old site's, which had "smrt grijeha".
- **Missing texts.** The collect *Gregem tuum* of St Urban and of Sts Soter and Caius uses the old site's Croatian of the same prayer for other Popes with the names put in. St Maurice (collect, secret) and the gradual of the Queenship outside Paschaltide remain without Croatian. `ZA-PRIJEVOD.md` and `GAPS.md` are written by the build.
- **Fonts (replaces "the u→v feature is switched off").** The fonts are modified copies of EB Garamond in `src/site/fonts` (the Latin language system, which drew u as v, is removed; made by `scripts/fonts/make-fonts.py`, not needed for a build). New file names; a new version of the site reloads open pages once so that returning visitors get them. EB Garamond names no Reserved Font Name.
- **Links.** `m` in a link selects a tab only as a whole number in range; a date that does not exist opens today.
- **Tests.** `npm test` builds the site first, because the text tests read `dist` as the browser does. `npm run verify:site` runs the browser checks in Chromium and WebKit.
- **Firefox.** Playwright's Firefox does not start on this machine (macOS 27.2: "Could not find profile folder"); the cross-browser checks ran in Chromium and WebKit and name Firefox as skipped (`BLOCKED.md`).
- **Handover (Nov 2026).** The repository builds and passes its tests and the whole-site crawl from a fresh clone with Node.js alone (proved in a clone of the public repository). `README.md` (Croatian) is the maintenance guide; `CLAUDE.md` is now a short brief for work with Claude Code and the original brief is `docs/ORIGINAL-BRIEF.md`; the files of the first unattended run are in `docs/build-log/`. The comparison with Missale Meum uses a saved table of its English titles and ids (`data/raw/mm/title-ids.json`) when that project's source is not present. Saved verification results no longer contain paths of the computer they were made on. Kniewald's page scans are fetched per page with `scripts/kniewald/img.sh <1942|1930> <leaf>` (two printed pages per leaf).
