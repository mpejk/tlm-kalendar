# Suspected typos in the Croatian of the old site

Generated by `npx tsx scripts/verify/typos.ts` from the harvested pages. **Nothing here has been corrected**: the site shows the Croatian exactly as tradicionalnamisa.com printed it. The tests are mechanical (no dictionary), so each list contains false alarms; they are sorted so that the likeliest come first.

To correct one after checking it: put the corrected cell in `data/tm/manual.json` (or fix the word in `data/tm/blocks.json`) and run `npm run build`.
